# Appointment System

This project is the backend API for a college appointment system. It provides a set of RESTful endpoints to manage users, schedules, and appointments..

## Core Features

*   **User Authentication:** Separate registration and login for students and professors.
*   **Availability Management:** Professors can define their available time slots for appointments.
*   **Appointment Booking:** Students can browse professors' schedules and book an available slot.
*   **Appointment Management:** Professors can cancel or mark appointments as completed.
